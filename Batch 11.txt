## Step 3 — Six surgical patches (apply by hand; too large to re-emit whole)

**1. `packages/brain/src/anomaly.ts` — silence detector crashes** (`max(gap)` is an interval, not a timestamp, so `s.last.getTime()` throws and the detector never runs). Replace `silenceDetector()` with:

```typescript
async function silenceDetector(): Promise<AnomalyDraft[]> {
  const rows = await brainDb.$queryRaw<Array<{ source: string; last: Date; p50h: number }>>`
    WITH gaps AS (
      SELECT source,
             EXTRACT(EPOCH FROM (at - lag(at) OVER (PARTITION BY source ORDER BY at))) / 3600 AS gap_h
      FROM "BrainEvent" WHERE at > now() - interval '7 days'
    ),
    med AS (
      SELECT source, percentile_cont(0.5) WITHIN GROUP (ORDER BY gap_h) AS p50h
      FROM gaps WHERE gap_h IS NOT NULL GROUP BY source
      HAVING percentile_cont(0.5) WITHIN GROUP (ORDER BY gap_h) > 0
    ),
    lastseen AS (
      SELECT source, max(at) AS last FROM "BrainEvent" GROUP BY source
    )
    SELECT m.source, l.last, m.p50h FROM med m JOIN lastseen l ON l.source = m.source`;
  return rows
    .filter((s) => (Date.now() - s.last.getTime()) / 3_600_000 > Number(s.p50h) * 3)
    .map((s) => ({
      detector: "silence", subsystem: s.source, metric: "hours_since_last_event",
      value: Math.round(((Date.now() - s.last.getTime()) / 3_600_000) * 10) / 10,
      baseline: Math.round(Number(s.p50h) * 10) / 10,
      severity: "CRITICAL" as const, details: { lastAt: s.last.toISOString() },
    }));
}
```
